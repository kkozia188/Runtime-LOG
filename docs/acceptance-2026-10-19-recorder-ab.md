# A/B 验收：记录控制器接入实机控制循环（2026-10-19）

## 条件

- 台架 Alfa_V3-bench-01，`bench_left_arm` 运动 scope，1 kHz，驱动 OP、失能、无人操作。
- 记录控制器 `runtime_log_recorder` 提交 `df9dc89`（Release），32 个字段（7 轴位置/数字输入/状态字、过程数据年龄、
  主站链路/应答数/WKC 错误计数、7 个从站 AL 状态），2000 槽，段 644 KB，已 mlock。
- Runtime-LOG 服务运行（主站轮询默认 5/1 Hz，黑匣子读者每 50 ms）。
- 测量：`tools/ab_jitter.sh <out> 600 asis`，CPU14 上 `sched_switch`，RT 线程相邻切入间隔，每组 600 s。

## 结果

| 组 | 周期 | 标准差 µs | 偏差 p99 / p99.9 / 最大 µs | > 50 µs | 丢帧 / 发送错误 | CPU14 外来进程 |
| --- | --- | --- | --- | --- | --- | --- |
| A：未加载（上一次启动） | 600003 | 0.524 | 3 / 5 / 9 | 0 | 0 / 0 | 无 |
| B：激活 | 600003 | 0.866 | 4 / 5 / 9 | 0 | 0 / 0 | 无 |
| C：同一次启动，停用 | 600003 | 0.881 | 4 / 5 / 9 | 0 | 0 / 0 | 无 |

- B ≈ C：标准差的差异来自两次栈启动之间，不来自记录控制器；尾部指标三组相同。
- 记录控制器自报的实际周期（B 期间）：最小 991.9 µs，最大 1008.3 µs，超过 1.5 倍名义周期 0 次；读者缺口 0。
- 手动触发：12001 周期窗口（前 10 s / 后 2 s），无缺失，MCAP 687 KB，可读。
- 停后 SDO：7 轴 0x603F/0x6041 读取成功。

## 结论

PASS：记录控制器对 1 kHz 控制循环无可测影响。台架部署默认开启。

## 限制

- 失能状态测量；使能运动时未单独复测（写入量与是否运动无关）。
- 记录控制器每周期耗时没有在实机控制循环里单独打点；依据微基准（7 轴档 p99.9 < 0.1 µs，最坏 4.4 µs）。
- 服务重启时黑匣子的周期统计重新开始计数。
