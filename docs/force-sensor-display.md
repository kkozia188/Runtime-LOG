# 六维力网页显示

首页的“实时状态 / 左右臂六维力”链接打开 `/live`。每个通道上方显示协议换算值，下方保留整数原始值 `raw`；左右侧分别显示采集状态、采样计数、状态码、温度原始值和记录滞后。

## 通道与单位

按《六维力传感器-EtherCAT通讯协议 V1.1》（2026-09-10）的 TxPDO 定义：

| 对象 | 通道 | 换算 | 单位 |
| --- | --- | --- | --- |
| `0x6000:01..03` | Fx、Fy、Fz | raw ÷ 100000 | N |
| `0x6000:04..06` | Mx、My、Mz | raw ÷ 100000 | N·m |

换算值保留五位小数。例如 `raw -97424` 显示为 `-0.97424 N`。协议文件 SHA256 为 `9c275c21bb171a99cd814c2a041b8bc9b03774ef1034cac523104c1e63ab8cdf`。这是协议单位换算，不包含安装标定、坐标变换、去零或重力补偿。

状态码和温度属于协议保留字段，仅展示 raw。采样计数为无符号 32 位运行毫秒计数，回绕后继续计数；本页不据此推断故障位或配置采样超时。

## 数据来源与状态

页面读取现有 Runtime-LOG 共享内存记录段中的 `left_wrist_force_sensor` 和 `right_wrist_force_sensor`。六通道状态接口名为 `channel_1_raw` 至 `channel_6_raw`，辅助字段为 `sample_counter_raw`、`status_code_raw` 和 `temperature_raw`。当前设备映射的左右从站位置分别为 8、16；不同拓扑需要另行核对，不能直接套用。

- 未接入、缺失或非有限读数显示横线，不用零值替代。
- 记录段停用、写入进程退出或记录过期时，页面显示相应状态。
- 已记录的链路或从站状态未就绪时，页面标记“总线未就绪”。
- “周期记录更新”表示记录器仍在更新，不保证传感器产生了新样本；采样是否推进需查看采样计数。
- 控制进程已退出的运行不再显示于实时页；历史归档保持不变。
- HTTP 请求失败时清除实时读数，并显示连接中断提示。

`/live.json` 在每个运行的 `force_sensors` 中返回 `raw`、`converted`、`units` 和状态信息；没有运行时，顶层 `force_sensors` 仍返回左右侧未接入状态。此功能只读现有记录，不发送 EtherCAT、使能、复位、运动或清零命令。

## 验证

运行 `python3 -m pytest -q tests/test_live.py` 验证 API、DINT 极值、负数、零值、缺失/非有限值和失效状态。完整仓库测试使用 `python3 -m pytest -q tests`。

已在左侧在线设备验证六通道 raw 与换算值一致、采样计数推进；右侧未接入显示横线。部署主机的完整测试曾有共享内存压力测试未达到有效读取数量阈值，没有触发数据撕裂断言；这不构成长期实时性或传感器受力标定验收。

2026-10-31 上库前验证：最新主线上的完整测试为 109 通过、1 失败。失败项 `test_concurrent_reading_never_returns_torn_slots` 的有效读取数量为 58，未达到大于 1000 的要求；共享内存实现和该测试均未修改。六维力相关 7 项测试及 JavaScript 表格函数执行检查通过。浏览器截图外观检查未完成。
